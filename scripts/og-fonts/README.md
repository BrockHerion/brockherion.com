Latin subsets of Cormorant Garamond 400 and Lora 400, pulled from Google Fonts.

Vendored rather than fetched at run time so `generate-og.mjs` produces the same
card on any machine, with no network. A card that silently falls back to Times
is worse than one that fails loudly.
